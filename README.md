# ⚡ 수강신청 초정밀 타이머 & 자동 클릭 보조 프로그램 v1.1

수강신청, 수강정정, 티켓팅 등 **정확한 시각(마이크로초 단위)에 지정된 화면 위치(X, Y)를 자동으로 클릭**해 주는 초정밀 타이머 및 클릭 매크로 프로그램입니다.

---

## 🌟 주요 특징 및 커스텀 목표 시간 기능

1. **자유로운 커스텀 목표 시각 설정 (Dynamic Time Parsing)**:
   - **자연어 및 다양한 입력 지원**:
     - 표준 형식: `10:00:00.000`, `10:00:00`, `10:00`
     - 연속 숫자: `100000` (10시0분0초), `093000`, `1400`
     - 한글 표현: `10시`, `오후 2시 30분`, `10시 0분 0초 500밀리초`
     - 상대 시간: `+10초`, `+1분`, `+5분`, `+1시간`
     - 날짜 지정: `내일 10:00:00`, `2026-08-13 10:00:00`
   - **실시간 프리뷰 (Live Preview)**: 입력과 동시에 해석된 실제 목표 시각(KST) 및 남은 시간(초)을 실시간으로 안내합니다.

2. **🎛️ 타임 피커 (Time Picker) 팝업 제공**:
   - `[🎛️ 시간 선택 팝업]` 버튼을 눌러 **시 / 분 / 초 / 밀리초(ms)** 드롭다운 및 스핀박스로 시각을 직관적으로 맞출 수 있습니다.

3. **⚡ 빠른 프리셋 & 상대 조정 버튼**:
   - `09:00`, `10:00`, `14:00`, `17:00` 주요 수강신청 시각 원클릭 적용
   - `+5초`, `+10초`, `+1분`, `+5분`, `다음 정각` 조정 버튼 지원

4. **초정밀 타이머 & 딜레이 보정 (Delay Compensation)**:
   - `time.perf_counter()` 기반 마이크로초(μs) 단위 고정밀 타임 루프 사용.
   - 네트워크 반응속도(Ping)를 고려한 **딜레이 보정 기능** 지원 (예: `-50ms` 설정 시 정각보다 0.05초 일찍 클릭하여 서버 도착 시간 최적화).

5. **서버 시간 동기화 (Navyism / 대학 수강신청 서버)**:
   - 수강신청 서버 URL (예: `sugang.knu.ac.kr`)을 입력하면 HTTP Response Header의 `Date`를 기반으로 서버 시간 및 RTT(Ping) 오차를 자동 계산하여 동기화합니다.

6. **글로벌 단축키 지원 (Global Hotkeys)**:
   - **`F2`**: 마우스 좌표 캡처 (원하는 수강신청 버튼 위에 마우스를 올린 후 `F2` 조작)
   - **`F5`**: 예약 시작 (타이머 가동)
   - **`F6` 또는 `ESC`**: 긴급 중지 / 예약 취소

## 🚀 실행 방법

### 1. 패키지 설치
터미널 또는 명령 프롬프트(CMD)에서 아래 명령어를 실행하여 필요 라이브러리를 설치합니다:
```bash
pip install -r requirements.txt
```

### 2. 프로그램 실행
```bash
python main.py
```
